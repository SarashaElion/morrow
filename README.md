# MORROW

> **Do not only remember what you chose. Remember what your choice made impossible.**

MORROW is an open protocol for **counterfactual provenance** and **machine inheritance** in agentic systems.

It is being developed as infrastructure for preserving not only what an agent did, but the decision-space surrounding consequential actions: alternatives considered, possibilities foreclosed, reversibility windows, assumptions, authority, and conditions under which a future system should reconsider the inherited decision.

The public repository will contain the protocol, schemas, reference implementation, conformance tests, and examples. Advanced implementation work that creates strategic or commercial leverage may live outside this repository.

**Status:** pre-v0.1 seed.
